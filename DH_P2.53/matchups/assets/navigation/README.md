# Matchups navigation icons

These are the unmodified Font Awesome Free 6.5.1 solid icons used by DH's
LeagueHub navigation, copied here so Matchups owns its navigation assets.
CSS masks give them the button's current color without another font dependency.

Source: https://github.com/FortAwesome/Font-Awesome/tree/6.5.1/svgs/solid
